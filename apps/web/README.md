# GenFlow Web

Remix frontend for the GenFlow Gateway — business position generation and candidate matching platform.

## Development

```bash
# From repository root
pnpm install
pnpm --filter @genflow/web dev
```

## Environment

Set `NEXT_PUBLIC_API_URL` to the Gateway URL (default: `http://localhost:3000`).

## Build

```bash
pnpm --filter @genflow/web build
```
